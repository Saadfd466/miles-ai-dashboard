# Miles AI Dashboard

A 3D interactive multi-agent system dashboard with live chat functionality.

## Features

- **3D Visualization**: Interactive Three.js scene with animated agent nodes
- **4 Agents**: Miles (Leader), Nova (Execution), Nexus (Integration), Wanda (Workflow)
- **Live Chat**: Real-time chat panel with agent avatars and typing indicators
- **Agent Details**: Click any agent to view role and description
- **Interactive Controls**: Drag to rotate, scroll to zoom

## Live Demo

URL: https://workspace-five-gray.vercel.app

## Local Usage

Open `index.html` in any modern browser.

## Agent System

| Agent | Role | Color | Shape |
|-------|------|-------|-------|
| Miles | Strategic Leader | Cyan | Icosahedron |
| Nova | Execution Agent | Red | Cube |
| Nexus | Integration Agent | Teal | Octahedron |
| Wanda | Workflow Agent | Yellow | Torus |

## Tech Stack

- Three.js for 3D graphics
- Vanilla JavaScript
- CSS3 animations
- No build step required
